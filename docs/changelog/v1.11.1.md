Fix for YouTube search on all phones

- YouTube search results using the new lockup format now show up again
- Live streams and Shorts stay filtered out of song results
- Settings self-test now fails when search returns no songs, with result-shape details
- Server fallback is used when on-device search comes back empty
- Search results appear as each source answers, instead of waiting for the slowest source
- Previous searches open instantly from saved results, even offline
- Old requests are cancelled and duplicate searches share one call on slow networks
