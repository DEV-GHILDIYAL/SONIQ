# v1.7.0: Diwali, themes, fonts, clan settings

## Diwali (src/lib/festival.ts)
- Dates table per year (2026-11-08). Season = 2 days before .. 4 days after; Diwali day = fireworks.
- Home `DiwaliBanner` (season only): wish, 3 mixes built by search (round-robin across queries,
  user's favourites first, diversify 25 / max 3 per artist), "Try the Diwali theme".
- `FestivalBurst`: emoji fireworks once on Diwali day (AsyncStorage key per year).
- Notification 09:30 on Diwali day (id soniq-festival, uses the "Your mixes" switch).
- DJ: Groq prompt gets a festive hint; Hindi template favourites line opens with Happy Diwali.

## Themes / fonts
- New themes: diwali, holi, monsoon, mumbai, sunset, mint, chai, royal, custom.
- Custom: `customOverrides(scheme, accent, bg)` derives accentSoft/onAccent/surfaces from one
  accent (24 swatches) + background dark | amoled | tint. Cached per accent+bg in `paletteFor`.
- Fonts: hind, mukta, baloo (Baloo 2), tiro (Tiro Devanagari Hindi, one weight), teko, righteous.
- Text size 0.9 / 1 / 1.12 / 1.25: `applyFont(id, scale)`; root Stack re-mounts on font+scale.
- Player background: blur (default) | gradient (accent glow) | solid.
- Not done: corner styles (StyleSheets are built at import time, would need a restart),
  hue slider (needs a native slider; 24 swatches instead).

## Clan settings
- SQL: clans.description, clans.max_members (2-30); `soniq_clan_update` (owner only, null =
  keep, cap >= current members), system message body `updated`. Join respects max_members.
- UI: clan menu > Clan settings (`ClanSettingsSheet`); header shows the description.
